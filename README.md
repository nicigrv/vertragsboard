# Vertragsboard

Windows-Desktop-App der Pfarrei St. Bonifatius zur Verwaltung des Einstellungsprozesses.

## Installation

Aktuellste Version herunterladen:

https://github.com/nicigrv/vertragsboard/releases/latest/download/Vertragsboard-Installer.zip

ZIP entpacken und `Vertragsboard-WebSetup.exe` doppelklicken.
